# ALS渐冻症患者动作呼叫装置

当渐冻症（ALS）患者很难按下呼叫按钮或发出足够响的声音时，可以尝试用自己还能控制的动作提醒身边的护理人员。这个项目是一个辅助呼叫原型。佩戴在手腕或小腿上的小型开发板将动作数据通过蓝牙发给 Android 手机，手机识别到符合规则的动作后持续响铃、振动，直到护理人员确认。

## 能做什么

- **默认模式**识别持续的来回动作。大动作约需 3 秒，小动作约需 4 秒，同时要达到幅度和连续性条件。
- **个性模式**用语音引导记录静息和呼叫动作，再做一轮独立验证。通过后可以启用个人规则，以适应较小或较慢的动作。佩戴位置改变、换设备或换人后应重新学习。
- **护理暂停和断线提醒**方便现场照护。暂停需二次确认，App 会语音提醒恢复。运行中断线时，手机会提示并尝试重连。
- **离线运行**。识别和响铃在手机上完成。当前每块开发板同时可连一部手机，适用于同一房间内的护理提醒。

## 如何试用

1. 准备一块带板载运动传感器的 **Seeed Studio XIAO nRF52840 Sense Plus**、USB 数据线、一条软绑带和一部 Android 手机。
2. 用 USB 将开发板接到电脑，快速双击板上的 **RST**。出现开发板启动盘后，把 `LegPhoneBLE.uf2` 拷入。开发板重启后可保持 USB 供电。已烧录本项目固件的开发板可直接使用。 [Seeed 官方入门说明](https://wiki.seeedstudio.com/XIAO_BLE/)
3. 安装 Android APK，打开「ALS渐冻症患者动作呼叫装置」。开启手机蓝牙，并允许「附近设备」和通知权限。点击「开始监听」，将开发板放稳，等界面显示「监测已开启」。
4. 到「设置 → 测试声音和振动」试响。由护理人员陪同，用佩戴者能重复做出的动作测试触发和确认。如果准备锁屏使用，也在该手机锁屏时实测一次。
5. 动作较弱时，可从「设置 → 监测模式与个性学习」进入学习。按引导静息 5 秒并做呼叫动作 5 秒，再完成静息 10 秒和动作 5 秒的独立验证。通过后点「使用个性模式」，再测试实际呼叫。

原型已在 Redmi K40 上验证过与新开发板的蓝牙连接和声振自检。0.8.2 已通过软件构建和回归检查，当前版本界面和 OPPO K11 实机连接仍待验收。试用时请保留原有呼叫方式，连接断开、设备没电或 App 停止时，手机无法接收新的动作呼叫。
